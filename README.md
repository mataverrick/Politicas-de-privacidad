POLÍTICA DE PRIVACIDAD

Última actualización: Junio 2026

Esta Política de Privacidad describe cómo se recopilan, utilizan y protegen los datos en esta aplicación (en adelante, "la Aplicación") en relación con la API de WhatsApp Business.

1. RECOPILACIÓN DE INFORMACIÓN
La Aplicación solo recopila y procesa la información estrictamente necesaria para el envío, recepción y automatización de mensajes a través de la API de WhatsApp, lo cual incluye de manera limitada:
- Números de teléfono de destino.
- Contenido de los mensajes de texto o archivos multimedia enviados por el usuario.
- Identificadores de mensajes compartidos por la plataforma de Meta.

2. USO DE LA INFORMACIÓN
Los datos procesados se utilizan exclusivamente para:
- Pruebas técnicas, desarrollo y optimización del sistema de mensajería.
- Validar el correcto funcionamiento de los Webhooks y la lógica de negocio de la Aplicación.
No utilizamos estos datos para fines comerciales, publicitarios ni de perfiles de usuario.

3. ALMACENAMIENTO Y SEGURIDAD
Nos comprometemos a garantizar la seguridad de los datos. La información procesada de manera temporal no se vende, alquila ni comparte con terceros. Todo el flujo de datos se realiza bajo los estándares de seguridad y cifrado que provee la infraestructura de Meta.

4. ELIMINACIÓN DE DATOS
Dado que la aplicación opera en un entorno de desarrollo/pruebas, los datos de los mensajes no se conservan a largo plazo. Si desea solicitar la eliminación de cualquier registro, puede ponerse en contacto con el administrador del sistema.
